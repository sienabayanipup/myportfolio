featured project

BSOA 2-7 Monitoring Portal

A centralized web portal I designed and built to bring attendance, student records, and class activity into one place — live and in use.

sienabayanipup.github.io/bsoa27portal
View Live Project ↗

A single source of truth for a whole class section.

Problem

Attendance, student information, and activity updates for the BSOA 2-7 section were scattered across separate sheets and manual checks, making it hard to get a quick, reliable overview.

Approach

I designed a centralized monitoring portal that brings the core functions — attendance, student lookup, activity tracking, an overview dashboard, and announcements — into a single web interface, connected to Google Sheets for live data.

Solution

The portal now runs as a live, hosted site with dedicated views for attendance records, individual student lookup, activity logs, a summary overview, and section announcements.
